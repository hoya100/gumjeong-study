# 검정고시 연습 퀴즈

검정고시를 준비하며 직접 공부하고 만든 무료 한국사 퀴즈 사이트예요.

👉 **바로 풀기: https://hoya100.github.io/gumjeong-study/**

## 무엇을 할 수 있나요

- **사건 순서 맞히기(흐름 문제)**: 한국사는 흐름이에요. 사건 4개를 일어난 순서대로 눌러요.
- **단원별 풀기와 약점 지도**: 단원마다 정답률을 보여주고, 가장 약한 단원을 알려줘요.
- **1·3·7일 자동 복습**: 틀린 문제를 잊어버릴 때쯤 다시 내줘요.
- **오답노트**: 틀린 문제만 모아서 다시 풀어요. 맞히면 자동으로 빠져요.
- 가입이 필요 없고, 기록은 내 브라우저에만 저장돼요.

## 문제는 어떻게 만드나요

- 모든 문제는 2015 개정 교육과정 한국사 범위에 맞춰 **AI(Claude)의 도움으로 새로 만든 연습 문제**예요. 공식 기출문제가 아니고, 기출문제를 옮겨 오지 않아요.
- 문제를 만들지 않은 **별도의 AI 검증 단계**에서 정답을 가리고 다시 풀어보고, 해설의 사실관계까지 점검한 뒤 통과한 것만 올려요.
- 한국교육과정평가원·시도교육청 등 시험 주관 기관과 관계없는 개인 사이트예요.
- 그래도 틀린 곳을 발견하면 문제 아래의 "문제에 오류가 있나요?"로 알려주세요.

## 폴더 구조 (만드는 사람용)

```
index.html          화면 뼈대
style.css           디자인
app.js              동작
og-image.png        링크 미리보기 그림
favicon.svg         탭 아이콘
data/config.json    과목 목록, 단원, 링크 설정
data/history.json   한국사 문제
tools/              문제 만들기·검사 스크립트 (사이트 동작과 무관)
```

사이트를 고친 뒤에는 `index.html`의 `?v=` 숫자를 한 칸 올려요. 방문자 브라우저가 옛 파일 대신 새 파일을 받게 하는 장치예요.
